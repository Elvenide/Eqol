# Eqol — Elvenide's Quality of Life for Main Sequence

**Eqol** is a collection of vanilla-friendly, client-side quality-of-life improvements for **Main Sequence**, built with UE4SS Lua.

Every feature in Eqol is designed to feel native to the base game—matching its exact UI style—and is **100% save-safe and removable** without adding custom items, machines, or save dependencies.

## Getting Started

- **[Getting Started & Installation Guide](docs/get-started.md)**

## Features

- **[Power Overview Hotkey & Summary Bars](docs/power-overview.md)** — Open the Power Overview from anywhere in a station or ship (`P`, rebindable in Settings → Controls) and view Production, Consumption, and Power Satisfaction progress bars at a glance.
- **[2D Station Minimap HUD](docs/station-minimap.md)** — Bottom-left 5×5 module-scale minimap of your current station floor with machine footprints and toggleable item icons.
- **[Full Station Map UI](docs/station-map.md)** — Floor-by-floor 2D station view accessible from the Map UI, with conveyor/machine item icons, remote machine building (`B`), and single/multi-machine copy-and-paste.
- **[Logistics UI Screen](docs/logistics.md)** — Icon-heavy station storage overview and machine production/consumption rate monitor with bottleneck indicators (`L`, rebindable in Settings → Controls, with bottom-right HUD indicator).
- **[Designer Power Stats](docs/designer-power-stats.md)** — Displays total Power Generation and Power Consumption alongside Hull and Mass in the Ship Designer and Station Designer.
- **[Cinematic Freecam](docs/cinematic-freecam.md)** — Single keybind (`F9`, rebindable) to toggle Spectator Mode and Hide HUD together.
- **[Ship 3rd-Person Perspective & Scroll Zoom](docs/ship-camera.md)** — Toggle 1st/3rd-person ship camera (`V`, rebindable) and adjust distance with the mouse scroll wheel.
- **[Scroll to Rotate Conveyor Belts](docs/conveyor-scroll-rotate.md)** — Use the mouse scroll wheel to rotate conveyor belts while building, in addition to `R`.
- **[Ship Instant Zero Throttle](docs/ship-zero-throttle.md)** — Instantly set ship throttle/acceleration to `0` with a single keypress (`0`, rebindable).
- **[Player Nametags](docs/player-nametags.md)** — Floating nametags above all players (including yourself) with Online/Offline status indicators.
- **[Player Markers on Maps & Minimap](docs/player-map-markers.md)** — Exact player positions and nametags on the World Map, Station Map, and Station Minimap.
- **[Player Join & Leave Alerts](docs/player-alerts.md)** — Native HUD alerts when players (including the host) join or leave the game.
