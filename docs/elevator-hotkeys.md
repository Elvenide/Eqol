# Elevator Floor Hotkeys

Press number keys **`1`–`9`** (or **`0`** for Floor 10) while inside an elevator pod -- with or without the elevator UI open -- to immediately send the elevator to that floor.

## Usage

- Stand inside any station elevator pod (or have the elevator floor selection menu open).
- Press **`1`–`9`** (top number row or numpad) to travel to Floors 1–9, or **`0`** for Floor 10.
- Automatically suppresses the hotbar build-mode trigger when pressing number keys inside an elevator, and ignores keypresses while typing in chat or rebinding keys.
- Uses the game's native pathways so floor travel stays deterministic and multiplayer-safe.
