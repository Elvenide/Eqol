# Ship Instant Zero Throttle

Instantly cut your spaceship's acceleration/throttle to `0` with a single keypress.

## Usage

- Press **`0`** (default) while piloting a ship to immediately set throttle to `0`.

## Configuration

- **In-Game**: Open **Settings → Controls** and look for **Ship Zero Throttle** to rebind the key.
- **Config File**: Stored in `Eqol/config.json` under `"ShipZeroThrottleKey"`.
